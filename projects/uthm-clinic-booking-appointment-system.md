# 📌Healthcare Appointment Booking System (System Analysis & Design)

A real-world system analysis and design case study for an online clinic appointment booking system. This project analyzes an existing manual appointment process and proposes a structured web-based solution to improve operational efficiency, reduce booking errors, and enhance patient experience.

## 🧠Features

- Real client-based system analysis (Klinik Ceria, Batu Pahat)
- End-to-end Waterfall SDLC implementation
- Requirement gathering through stakeholder interviews
- Complete system documentation (DFD, ERD, feasibility study)
- User-friendly and mobile-responsive system design
- Centralized appointment management concept

## 🛠️Project Background

This project was conducted for **Klinik Ceria**, a healthcare clinic that previously relied on manual appointment booking through phone calls and social media platforms such as WhatsApp. This approach resulted in long waiting times, missed appointments, and increased administrative workload. The project was completed as part of **BIC21003: System Analysis and Design**, applying structured SDLC practices to solve a real organizational problem.

## 🎯Problem Statement

- Klinik Ceria relied on manual appointment booking via phone calls and social media platforms ( WhatsApp), which caused:
- Long waiting times
- Missed or overlooked appointments
- High administrative workload for clinic staff
- Difficulty in booking appointments in advance
This highlighted the need for a centralized, online appointment booking system.

## ✅Objectives

- Analyze the existing manual appointment booking workflow
- Identify system problems and inefficiencies
- Gather functional and non-functional requirements from stakeholders
- Design a centralized online appointment booking system
- Apply Waterfall SDLC methodology in a real-world context
- Produce complete system analysis and design documentation

## 🔗Methodology

**Software Development Life Cycle (SDLC):**
- Waterfall Model  
  (Planning → Analysis → Design → Implementation → Maintenance)

**Requirement Elicitation Techniques:**
- Stakeholder interview (clinic doctor)

## 🧩System Scope & Designed Features

- Responsive and mobile-friendly interface design
