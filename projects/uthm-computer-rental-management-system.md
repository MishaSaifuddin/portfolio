# 💻 Computer Rental Management System (Secure System Design & Analysis)

A secure, web-based **Computer Rental Management System** designed to automate rental operations, inventory management, and customer handling. This project focuses on **system design, implementation, and security controls**, incorporating **threat modeling and risk mitigation using the STRIDE framework** 🔐.

## ✨ Features

- 🔄 Automated computer rental and return management  
- 🗂 Centralized inventory and supplier management  
- 👥 Admin and customer role separation  
- 🔐 Secure authentication with CAPTCHA and OTP  
- 🔑 Password hashing and secure session management  
- 🛡 STRIDE-based threat modeling and mitigation  
- 📊 Detailed admin dashboard and customer portal  

## 🏢 Project Background

The Computer Rental Management System was developed for **Sinaro**, an organization that previously relied on **manual, paper-based processes** for computer rentals, inventory tracking, and maintenance scheduling. These manual processes resulted in **operational inefficiencies, data inconsistency, and poor user experience**.

This project proposes a **secure and automated system** to enhance operational efficiency, reduce errors, and improve data security. It was developed as part of an **Information Security Project**, emphasizing **secure system implementation and risk management**.

## ⚠️ Problem Statement

- ❌ Manual booking and inventory tracking caused delays and frequent errors  
- ❌ Lack of centralized system led to ineffective inventory and maintenance management  
- ❌ Poor user experience for both customers and staff  
- ❌ Increased security risks due to absence of structured security controls  

## 🎯 Project Objectives

- ✅ Design an automated computer rental system to replace manual processes  
- ✅ Improve inventory and rental management efficiency  
- ✅ Enhance system security using encryption and authentication mechanisms  
- ✅ Apply threat modeling to identify and mitigate security risks  
- ✅ Develop and test a secure system prototype  

## 🧩 System Design

### 👤 User Roles

- **Admin**
  - Manage categories, suppliers, computers, and rentals  
  - Monitor registered customers  
  - Block or unblock user accounts  
  - View system dashboards and reports  

- **Customer / Company**
  - Register and manage profile  
  - View available computers  
  - Rent and track issued computers  
  - Update account information securely  

### 🧱 Core Modules

- Home Page (Admin & Customer Login)
- Admin Dashboard
- Category, Supplier, and Computer Management
- Rental and Return Management
- Customer Dashboard and Profile Management

## 🔐 Security Implementation

This system applies a **layered security approach** to protect sensitive data and ensure system integrity.

### 🧠 Threat Modeling (STRIDE)

- **Spoofing** – CAPTCHA, Email OTP, Authentication  
- **Tampering** – Password hashing and encryption  
- **Repudiation** – Logging and access control  
- **Information Disclosure** – Encrypted sensitive data  
- **Denial of Service (DoS)** – Detection and mitigation strategies  
- **Elevation of Privilege** – Role-based access control  

### 🛠 Security Controls Implemented

- CAPTCHA to prevent automated attacks 🤖  
- Password hashing using secure algorithms 🔑  
- Email OTP verification 📧  
- Strong password policy enforcement 🔒  
- Secure session management 🧾  
- Authentication and authorization controls 🛂
