# 🏨 Presto Hotel Booking System

A secure, user-friendly, and database-driven **Hotel Booking System** developed as an academic and portfolio project.  
This system modernizes traditional hotel reservation processes by replacing paper-based workflows with a fully digital platform while prioritizing **security, usability, and scalability** 🔐✨.

---

## 🚀 Project Overview

The **Presto Hotel Booking System** is a web-based application designed to streamline hotel reservations for both users and administrators.  
It focuses on improving operational efficiency, enhancing user experience, and enforcing strong security practices aligned with **OWASP standards**.

This project demonstrates my skills in:
- Database design & normalization
- Secure system development
- Web-based system analysis
- Software engineering best practices

---

## 🎯 Objectives

- 🖥️ Design an **intuitive and user-friendly interface**
- 🔐 Develop a **secure system** following OWASP secure coding principles
- ⚙️ Improve booking efficiency and reduce manual errors
- 🧪 Test system security against common vulnerabilities (SQLi, XSS)
- 📊 Enable effective **admin-side booking management**

---

## ✨ Key Features

### 👤 User Features
- User registration & secure login
- Password complexity enforcement
- Hotel room booking with check-in/check-out dates
- View, manage, and cancel bookings
- Booking confirmation & invoice generation

### 🛠️ Admin Features
- Admin dashboard for booking management
- Modify or cancel user bookings
- Update booking status (confirmed, pending, cancelled)
- View booking records and system activity

### 🔐 Security Features
- Password hashing and secure authentication
- Input validation & sanitization
- Protection against SQL Injection (SQLi) & Cross-Site Scripting (XSS)
- Role-Based Access Control (RBAC)
- Secure data storage and encrypted communication (TLS)

---

## 🗄️ Database Design

- Relational database using **MySQL**
- Fully normalized schema (1NF, 2NF, 3NF)
- Clearly defined entities:
  - Users
  - Admin
  - Bookings
- Strong use of:
  - Primary keys
  - Foreign keys
  - Constraints for data integrity

📌 Designed to ensure **data consistency, security, and scalability**
