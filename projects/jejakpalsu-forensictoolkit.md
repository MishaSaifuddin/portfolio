# 🔍 JejakPalsu – Fake Receipt & Document Forensic Detection System

JejakPalsu is a **web-based digital forensic tool** designed to automatically detect **forged receipts and fake documents** using image processing, OCR, and noise analysis techniques.  
This project addresses real-world challenges in **financial fraud, document forgery, and digital evidence verification**, making it highly relevant for cybersecurity and digital forensic roles 🔐.

---

## 🚀 Project Overview

With the rise of digital fraud involving **fake receipts, invoices, and altered documents**, manual verification has become inefficient and error-prone.  
**JejakPalsu** provides an automated forensic solution to identify manipulation indicators such as:

- Font inconsistencies
- Cloned or duplicated logos
- Abnormal noise patterns
- Metadata irregularities

The system is built using **Python for backend processing** and **HTML/CSS for the frontend**, enabling investigators, auditors, and non-technical users to perform forensic checks easily through a web interface.

- 📄 Automated forensic report generation (PDF)
- 🌐 Web-based interface (Flask + HTML/CSS + phyton)

### Command-Line Interface (CLI)

Use the following commands to run the application via **Command Prompt / Windows PowerShell**:

```bash
pip install Pillow numpy opencv-python
pip install pdf2image
pip install Flask Pillow pypdf
pip install Flask Pillow pypdf weasyprint
```

Navigate to the project directory:
```bash
cd C:\FakeDocChecker
```

Graphical User Interface (GUI)
Run the Flask application:
```bash
flask run
```

Open your browser and access:
```bash
http://127.0.0.1:5000
```
